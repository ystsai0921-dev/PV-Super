二、 案場定位與地圖操作

在進行排板設計前，請先透過衛星地圖定位至目標案場位置：

  • 地址／關鍵字搜尋：在衛星地圖左下角搜尋框輸入地址、地標、地號或經緯度座標，點擊右側 搜尋 按鈕即可飛越至目標位置並置中顯示。
  • GPS 快速定位：點擊地圖右上角 按鈕，透過瀏覽器取得目前所在地的 GPS 座標。
  • 中心重置：點擊地圖右上角 按鈕，隨時將地圖視角重置對齊至目前案場中心。
  • 圖層切換選單：點擊地圖右下角 按鈕，可於 5 種圖資間自由切換：
    • Google 衛星混合圖：全球衛星空拍圖與繁體地名標注（預設推薦）。
    • 國土測繪航照圖：台灣本地公測空拍航照圖。
    • Esri 衛星地圖：全球高解析衛星影像。
    • 國土測繪電子地圖：台灣街道地圖與地籍基礎圖資。
    • OpenStreetMap：開放開源向量街道地圖。
  • 地面距離量測：點擊地圖右上角 按鈕，在衛星地圖上連續點擊以量測地面距離；按 Esc 鍵結束量測並清空標記。

三、 區域繪製與幾何編輯

透過左側邊欄頂部的開關切換繪圖模式，在地圖上繪製多邊形區域：

1. 案場範圍 (Boundary) ‧ 主要外框 編輯狀態：亮藍填色
  • 將左側 案場範圍 切換至 「編輯」 狀態。
  • 在地圖右下角浮動的範圍面板中點選 手繪多邊形，依序點擊案場角點，最後點擊起點完成閉合。
  • 頂點微調：多邊形各頂點皆具備圓形把手，可直接拖曳調整形狀，放開後內部排板即時重新計算。
  • 方位角自動推算：範圍閉合後，系統自動分析多邊形最長邊之法線方向，推算最佳方位角並填入試算表第 9 項。
  • 點擊懸浮確認框的 保留，並將控制項切換回 「鎖定」 狀態。
2. 排除區域 (Exclusion Zone) ‧ 採光罩／走道／保留區 編輯狀態：橘色填色
  • 將左側 排除區域 切換至 「編輯」 狀態。
  • 點選 手繪多邊形 繪製排除範圍，封閉多邊形各角點可自由拖曳調整。
  • 完成後切換回 「鎖定」 狀態，系統將自動扣除該區域內的所有模組並更新總發電量。
3. 障礙區域 (Obstacles) ‧ 水塔／女兒牆／機房／鄰棟 編輯狀態：紅色填色
  • 將左側 障礙區域 切換至 「編輯」 狀態。
  • 在障礙工具面板設定障礙物高度（公尺 m），並可勾選「在建物上」（預設開啟）。當案場為屋頂型（平屋頂/斜屋頂）時，障礙物高度將自動由該多邊形位置之屋頂高程起算往上疊加，且斜屋頂四周立面均保持完整封閉，無縫貼合屋面；未勾選則由地面起算。
  • 點選手繪多邊形描繪障礙物底面，閉合後即完成建立。
  • 3D 實體即時擠出：繪製完成後，3D 視圖即刻呈現半透明立體柱體。
  • 干涉扣除機制：當障礙物立體空間觸及太陽能模組或下方支架組件時，系統自動剔除受干涉模組並扣除容量。

物件調整工具箱 (Object Transform Toolbox)

在鎖定狀態下點選地圖上的任一多邊形，物件上方將浮現微型黑色調整面板：

選取物件 可用按鈕 操作說明
案場範圍 刪除 / 返回 點擊「刪除」清空案場邊界；點擊「返回」關閉面板。
排除區域 內縮 / 外擴 / 刪除 點選多邊形之某一邊線後，點擊「內縮」或「外擴」可將該邊線平行平移 0.5m；點擊「刪除」移除該排除區。
障礙區域 加高 / 降低 / 刪除 點擊「加高」或「降低」可增減障礙物高度 0.5m，並即時重新計算立體干涉；點擊「刪除」移除該障礙物。

多邊形快速複製、邊線吸附與極限微調縮放 (Advanced Map Editing)

  • 超高解析度極限縮放（Zoom 24）：地圖支援更深層的放大極限（最高 24 級放大），即便是 20kWp 以下之微型住宅屋頂，亦可清晰辨識並進行公分級精準微調。
  • 多邊形快速複製 (Duplicate Polygon)：
    • Windows 系統：按住鍵盤 Ctrl 鍵不放並拖曳既存之「排除」或「障礙」多邊形，即可直接拖曳複製出新多邊形。
    • Mac OS 系統：按住鍵盤 Cmd (⌘) 鍵不放並拖曳多邊形進行複製。
    • 觸控／行動裝置：在排除或障礙多邊形上方「連續點觸兩次 (Double Tap)」，系統即自動原地複製並選取新多邊形。
    • 光影輪動提示動效：觸發複製時，多邊形邊界具備高亮流光光影輪動動效，並於螢幕下方浮現複製成功提示標籤。
  • 自動吸附案場範圍邊線 (Edge Snapping)：拖曳或平移任何排除/障礙多邊形時，系統會自動搜尋案場範圍（Site Boundary）各頂點、中點及邊線投影，當游標接近時自動精準吸附對齊，確保留白或走道邊緣完全貼齊。

四、 試算表參數配置與運算規則

左側 Excel 參數控制表各欄位說明與幾何運算邏輯：

項目編號與名稱 可選值／單位 說明與操作方式
1. 案場名稱 文字 案場識別名稱，將帶入專案簡報與匯出檔案中。
2. 案場型式 地面型 / 平屋頂 / 斜屋頂 選擇基礎場域結構型式。
3. 屋頂坡向 單斜 / 雙斜 當案場型式為「斜屋頂」時開放設定。
4. PV 擺放 直放 (Portrait) / 橫放 (Landscape) 切換太陽能模組之長短邊擺放朝向。
5–8. 模組規格 預設廠牌 / mm / Wp 內建 VSUN、LONGi、Motech、TSEC 等大廠標準尺寸，亦可選擇「自訂模組尺寸」自行輸入長度 (L)、寬度 (W) 與額定瓦數 (P)。
9. 方位角 度 (°) 模組陣列朝向角度（0° 正北、90° 正東、180° 正南、270° 正西）。提供 135°、225°、90°、180°、270° 快捷節點與 ±0.5° 微調按鈕。
10–13. 陣列配置 數值 包含橫向片數 (arrI)、縱向片數 (arrJ)、組列數量 (arrM) 與組列間距 (arrP)。第 10、11 項右側快捷節點提供 ->| 按鈕可一鍵自動取案場範圍內滿版最大片數；當組列數量 arrM = 1 時，第 13 項組列間距自動 Mute 鎖定。
14–15. 工程間距 mm 橫向間距 spX 提供 20、40、80 mm 快捷節點；縱向間距 spY 提供 26、50 mm 快捷節點。
16–19. 傾角與高度 度 (°) / mm / m • 安裝傾角 θ 提供 6°、8°、10° 快捷節點。
• 屋頂傾角與屋頂高度於屋頂型案場生效。
• 支架高度 h 提供 1m (1000mm)、2m (2000mm)、4m (4000mm) 快捷節點。
20–23. 計算輸出 kWp / 片 / m² 系統依排板幾何即時計算之總裝置容量、總片數與陣列佔地面積。

斜屋頂結構模式判斷（平鋪 vs. 架高）

  • 平鋪模式（安裝傾角 = 屋頂傾角）：系統自動判定為平鋪結構。模組底面離屋面固定 200mm，每片模組下方配置 2 支專用陽極鋁軌，均勻分布於離模組兩端各 1/5 長度處。
  • 架高模式（安裝傾角 ≠ 屋頂傾角）：系統自動判定為架高結構。支架高度 h 代表陣列最高點之離地/離屋面高度，自動生成斜撐鋼樑、立柱與基座支撐。

五、 3D 視角操控與日照模擬

3D 視圖視窗支援多種視角模式、空間量測與即時日照陰影模擬：

控制按鈕 名稱 操作功能說明
重設視角 將相機視角重置回預設 45° 等角透視視角（Perspective View）。
俯視視角 切換至正上方垂直向下之俯瞰視角（Top View）。
側視視角 切換至水平橫向側視角度（Side View），檢視陣列坡度與支架高度。
Normal 視角 點選特定平面後，將視角自動垂直對齊該平面法向。
Zoom to Fit 自動計算案場邊界包圍盒，將所有模型結構置中填滿畫面。
3D 距離量測 在 3D 空間中連續點選模型節點以量測真實空間距離，按 Esc 結束量測。

日照模擬與顯示設定

  • 月份滑桿：模擬全年度太陽高度角變化，備有 6/21 (夏至) 與 12/21 (冬至) 快捷按鈕。
  • 時刻滑桿：模擬全日日照軌跡與陰影投射，備有 09:00 與 15:00 快捷按鈕。
  • 顯示設定面板（右下角）：
    • 光影開關：開啟或關閉 3D 視場之即時太陽光影追蹤。
    • 支架開關（全開／全關）：一鍵控制全場支架結構（鋼樑、斜撐、立柱、鋁導軌、基樁）之顯示與隱藏；關閉時僅保留太陽能模組懸浮顯示。
  • 右鍵快捷匯出選單：在 3D 視圖內任一處點擊滑鼠右鍵：
    • 📷 擷取 3D 圖片 (PNG)：輸出 3840px 高解析度 4K PNG 圖片。
    • 📐 匯出向量圖 (SVG)：將目前 3D 視場線條轉換為 1920×1080 向量 SVG 圖檔。

六、 資料管理與成果輸出

系統提供多種專案輸出與設定檔儲存功能：

  • 匯出案場簡報 (A4 橫式 PDF)：點擊左側 匯出案場簡報，系統提供兩種視角擷取模式並自動生成 3 頁標準工程規劃報告：
    • ⚡ 自動截圖：由系統全自動最佳化視角並高速依序擷取。
    • 📷 手動截圖（互動取景）：進入 3D 視窗互動取景框（510×232 比例），提供 4 大視角切換按鈕（填滿畫面、俯視、側視、透視）與 + / − 縮放按鈕，依序引導自訂放大圖、透視圖、上視圖與側視圖（側視圖自動啟用平行投影 Orthographic Camera 與工程配色）。
    • Slide 1：專案綜述與技術參數表（案場名稱、經緯度座標、總裝置容量 kWp、模組總片數、排列間距與角度規格）。
    • Slide 2：3D 四視角模擬矩陣（包含等角透視圖、正上方俯視圖、局部特寫圖、與正交平行投影側視斷面圖，配置模組/支架/建物/地面圖例）。
    • Slide 3：衛星地圖邊界套疊圖（正方形 1:1 衛星空拍圖，範圍自動擴充 $\le 70\%$，帶入充足周邊地貌與道路）。
    • 全份簡報頁首頁尾均搭載新版 pv_super_logo_light.png 品牌識別標誌。
  • 匯出案場資料 (JSON)：點擊 匯出案場資料，將邊界座標、排除區、障礙物高度與所有試算表參數儲存為 JSON 檔案，便於日後重新載入或備份。
  • 預設值管理：
    • 儲存為預設：將當前試算表參數直接儲存至 defaults.json 與瀏覽器 LocalStorage。
    • 返回預設：放棄目前修改，將參數重置回 defaults.json 預設數值。
  • 目錄智慧記憶：系統透過 File System Access API 自動記錄上次匯出的資料夾路徑，連續輸出簡報與檔案時無需重複選擇目標路徑。
💡 鍵盤快速鍵與操作提示
• 距離量測中：按 Esc 鍵可退出量測模式並清除標記線。
• 頂點調整：在地圖多邊形編輯模式下，滑鼠拖曳頂點圓形把手即可即時調整幾何外框。
• 3D 視角旋轉：滑鼠左鍵拖曳旋轉視角、滑鼠右鍵拖曳平移視野、滾輪縮放視距。
