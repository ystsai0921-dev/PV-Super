一、 快速上手指南（五大規劃步驟）

本工具專為地面型與屋頂型太陽能案場提供即時三維排版、遮陰模擬與簡報匯出。操作流程共分為五個步驟：

步驟 1：定位 (Positioning) 空間座標

在開始設計前，先定位至目標案場之衛星圖位置：

  • 地址/關鍵字搜尋：在衛星地圖左下角搜尋框中輸入地址、地標或經緯度，點擊右側的 搜尋按鈕（深藍色高對比設計，內含白色放大鏡 SVG 圖示）即可精準移動並定位。
  • GPS 快速定位：點擊地圖右上角的 按鈕，透過瀏覽器直接抓取您目前的 GPS 座標。
  • 中心對齊：點擊地圖右上角的 按鈕，隨時將地圖視角重置對準案場中心。
  • 圖層選單切換：點擊地圖右下角的 圖層按鈕（採用自訂 layer.svg 向量圖標，透過 CSS background-image 覆蓋 Leaflet 預設圖示），可在以下五種地圖來源之間隨時切換：
    • Google 衛星混合圖（衛星 + 地名標注，推薦）
    • 國土測繪航照圖（台灣本地超高解析度航測）
    • Esri 衛星地圖（含道路標注）
    • 國土測繪電子地圖（台灣本地街道圖）
    • OpenStreetMap 道路圖
  • 距離量測（地圖）：點擊地圖右上角的 量測按鈕，可在地圖上連續點擊以量測實際地面距離，按 Esc 退出並清空。
步驟 2：範圍 (Boundary) ‧ 手繪多邊形邊界 編輯狀態：半透明亮藍填色

定義太陽能板鋪設的案場主要外框邊界：

  • 點擊左側控制區的 案場範圍 控制項，將滑桿切換至 「編輯」 狀態。此時側邊欄的案場規劃區塊會填入半透明亮藍色背景（rgba(14, 165, 233, 0.15)）與亮藍色邊框，提示您正處於案場範圍編輯中。
  • 地圖上將浮現 範圍工具面板 （位於地圖右下角，也可點擊地圖右下角快捷觸發按鈕開啟）。
  • 手繪多邊形：點選面板中的 手繪多邊形 後，依序點選角點於地圖上描繪案場外框，最後點擊起點閉合完成。各角點均備有亮藍色圓形微調把手，可直接滑鼠抓取任意角點拉動形變，放開後模組即時重新滿鋪計算。
  • 確認完成後，點選下方懸浮提示的 確定保留；若不滿意則點選 放棄。完成後將範圍滑桿切換回 「鎖定」 狀態。
步驟 3：參數與排版 (Parameters & Layout) ⚙️ 毫秒級運算

在左側側邊欄的試算表中調整參數，系統將即時計算並更新 3D 圖面：

  • 案場型式與坡向（第 2–3 項）：可選地面型、平屋頂或斜屋頂。單斜與雙斜為互斥 Checkbox。
  • PV 擺放選擇（第 4 項）：可選短向傾斜（橫放）或長向傾斜（直放）。
  • 模組規格（第 5 項）：支援快速選取 VSUN、隆基、茂迪、元晶等主流大廠，亦可選擇「自訂模組尺寸」後微調長、寬與額定功率 (Wp)。
  • 方位角（第 9 項）：提供 135°、225°（上方節點）與 90°、180°、270°（下方節點）快捷點擊，兩旁各備有 / ±0.5° 微調按鈕（SVG 向量圖示，由 CSS background-image 注入）。
  • 快捷節點與微調（第 10–19 項）：
    • 14. 橫向間距 x 提供 20、40、80 mm 快速點擊節點。
    • 15. 縱向間距 y 提供 26、50 mm 節點。
    • 16. 安裝傾角 θ 提供 6°、8°、10° 快捷節點。
    • 19. 支架高度 h 備有 1500、2500、3500 mm 快捷節點。
  • 向量 SVG 微調按鈕：各參數欄位兩側的 + 與 − 按鈕均採用純黑粗線條的 SVG 向量圖示（minus.svg / plus.svg），透過 CSS background-image 覆蓋，確保顯示清晰一致。
  • 雙重樣式鎖頭 (Padlock)：當參數鎖定時，鎖頭呈高對比鮮紅色背景、白色閉鎖圖樣與陰影；解鎖時則為灰色虛線框開鎖圖樣，狀態一目了然。鎖頭圖示由 JavaScript 在頁面初始化時動態注入 inline SVG（非 emoji），不受字體或系統渲染影響。
步驟 4：排除區域 (Exclusion Zone) 編輯狀態：半透明橘色填色

設定案場內不鋪設太陽能板的區域（例如管道、障礙周邊等）：

  • 將左側的 排除區域 控制項切換至 「編輯」 狀態。此時該側邊欄區塊會填入半透明橘色背景（rgba(249, 115, 22, 0.15)）與橘色外框。
  • 地圖上將浮現 排除工具面板 （位於地圖右下角）。
  • 繪製操作：點選 手繪多邊形 依序點選角點繪製排除區，最後點擊起點閉合完成。封閉多邊形各角點同樣備有橘色把手可隨時拉動形變。
  • 完成後，切換回 「鎖定」 狀態，內部排版將即時扣除該排除區域。
步驟 5：障礙物與動態日照模擬 (Obstacles & Sun Simulation) 編輯狀態：半透明紅色填色

設定案場周邊會遮擋陽光的立體障礙物（樹木、高牆、鄰棟建築等）：

  • 將左側的 障礙區域 控制項切換至 「編輯」 狀態。此時側邊欄的障礙規劃區塊會填入半透明紅色背景（rgba(239, 68, 68, 0.15)）與紅色外框。
  • 地圖上將浮現 障礙工具面板，可設定障礙物高度（m）並透過滑桿調整。
  • 繪製與地圖填色：點選 手繪多邊形 繪製障礙物範圍框，地圖上的多邊形填色統一為半透明紅色填色（rgba(239, 68, 68, 0.35)）與紅色虛線外框。
  • 無眩光三維視場：
    • 陽光反光弱化：3D 視場中大幅降低直射太陽光強度並調高環境光填補，呈現舒適的視覺效果。
    • 啞光無反射材質：太陽能板、金屬邊框、鋼構支架、鋁導軌等材質均採高粗糙度設定，徹底消除刺眼的白色反射強光，呈現高品質無眩光啞光霧面效果。
  • 快捷節點日照模擬： 透過 3D 視場下方的 月份 與 時間 滑動條，可即時進行陰影追蹤模擬：
    • 月份快捷節點：滑桿旁備有 6/21 (夏至) 與 12/21 (冬至) 節點，可快速點擊跳轉。
    • 時間快捷節點：備有 09:00 與 15:00 節點，點擊可快速查看早晨與午後的遮陰狀況。

二、 精簡調整工具箱 (Object Transform Toolbox)

在地圖鎖定狀態下，點選地圖上的任何多邊形物件，將於多邊形旁彈出微型黑白極簡調整卡片（深黑背景 rgba(15, 23, 42, 0.98)、白字與白色細邊框）：

對應物件 控制按鈕 操作說明與功能
案場範圍 刪除 / 返回 點擊 刪除 一鍵清空案場邊界；點擊 返回 關閉工具箱。
排除區域 內縮 / 外擴 / 刪除 • 點擊邊線後，可點選 內縮 / 外擴 將該條邊線往內/往外平行收縮或擴張 0.5m。
• 點擊 刪除 移除該排除區。
障礙區域 加高 / 降低 / 刪除 • 點擊 加高 或 降低 即可即時將立體障礙物增減 0.5m。
• 點擊 刪除 移除該障礙物。

三、 3D 視角操控

3D 視場標題列右側提供以下快速視角切換與工具按鈕：

按鈕圖示 功能說明
重設視角 重設回預設斜角透視視角。
俯視視角 切換至正上方俯瞰視角（Top View）。
側視視角 切換至側面水平視角（Side View）。
Normal 視角 點選某平面後以法向（垂直平面）方向填滿視場檢視。
Zoom to Fit 自動縮放並置中，讓所有物件完整填滿畫面。
距離量測 在 3D 視場中連續點選以量測實際距離，按 Esc 退出並清空標記。

四、 成果輸出

  • 匯出案場簡報：點擊左側動作區的 匯出案場簡報 按鈕，一鍵輸出 A4 橫式簡報 PDF。採用 2×2 高解析度排版，包含俯視局部圖、3D 透視圖、全區平面圖與側向斷面圖，並會自動記憶您的上一次儲存路徑。
  • 匯出案場資料：點擊 匯出案場資料 按鈕，可儲存完整的坐標、障礙物高度、排除區與試算表參數（JSON 格式），隨時一鍵重新載入。
  • 儲存為預設：點擊 儲存為預設 按鈕，將目前所有試算表參數儲存至瀏覽器本地（LocalStorage），供下次開啟時自動套用。
  • 返回預設：點擊 返回預設 按鈕，還原至上一次儲存的預設參數。
  • 3D 顯示設定：3D 視角右下角的 顯示設定 面板中提供 「光影」 與 「支架」 兩組開關，開啟狀態下切換為亮藍色背景（rgba(14, 165, 233, 1)），與整體介面色調統一。
💡 行動裝置 (Responsive Design) 觸控適配
在手機或平板上，B (數值) 欄位具備自適應觸控寬度；所有微型浮動工具箱與面板皆支援觸控拖曳；3D 月份/時間滑動圓點縮小以防止觸控區域擁擠；地圖中央配有「頁面滑動鎖」以利手指滾動網頁，排版無任何重疊或超出，隨手量測與參數調整皆可流暢運行。
